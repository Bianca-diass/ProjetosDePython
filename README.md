# Projetos Python

Coleção de scripts e aplicações simples desenvolvidos em Python para prática de lógica de programação.

## 🚀 Tecnologias
* **Python**

## 📁 Conteúdo do Repositório

* `Adivinhacao.py` - Jogo interativo de adivinhação de números.
* `AgendaContatos.py` - Aplicação para gestão e organização de contactos.
* `CalculadoraSimples.py` - Calculadora com operações matemáticas básicas.
* `Forca.py` - Jogo da Forca clássico em terminal.
* `IMC.py` - Calculadora do Índice de Massa Corporal (IMC).
